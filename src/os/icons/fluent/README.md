# App icons

Microsoft's open-source Fluent icons, used under the MIT licence (see the LICENSE files here):

- **Fluent UI System Icons** (color set), github.com/microsoft/fluentui-system-icons:
  about, experience, skills, achievements, casual, hobbies, photos, videos, mail, resume, update, settings, studio
- **Fluent Emoji** (flat color), github.com/microsoft/fluentui-emoji:
  projects (file folder), education (graduation cap), viewer3d (package), games (video game), paint (artist palette), recycle (wastebasket)

`terminal.svg` is an original drawing. No Windows logo or Windows application icon files are used.

To change an app's icon, replace `<app id>.svg` here; `src/os/apps/registry.js` picks files up by name.
